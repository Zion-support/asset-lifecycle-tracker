# Asset Lifecycle Tracker

> End-to-end IT asset tracking from procurement to retirement with refresh forecasting.

Tracks every asset's lifecycle, warranty and depreciation, and forecasts refresh budgets years ahead.

**Live:** https://ziontechgroup.com/asset-lifecycle-tracker/  
**Network hub:** https://github.com/Zion-support/zion-app-network

## Features
- Discovery, inventory and ownership tracking
- Warranty & EOL alerts via [warranty-lens](https://github.com/Zion-support/warranty-lens)
- Refresh-cycle forecasting and budget planning
- Depreciation reporting via [ai-asset-depreciation](https://github.com/Zion-support/ai-asset-depreciation)
